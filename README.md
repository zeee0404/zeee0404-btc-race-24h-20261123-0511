Trend Rider — a long-only cbBTC trading bot for the 24-hour BTC race. It buys with the full cash on the first tradable bar, rides the trend, and sells the whole position when the close falls 2% below the running peak since entry. After a stop-out it re-enters only while the 60-bar return is positive, so a falling market cannot make it buy the same dip over and over. On the dev window it scores +$33.62 net PnL on 1,000 USDC start, 2 trades, max drawdown 1.98%.

## Run it

```sh
node main.ts
```
